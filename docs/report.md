# Звіт до лабораторної роботи 4

1. **Що змінилося у виводі git status після git add?**
   Файли перемістилися до списку "Changes to be committed", тобто були додані до індексу і готові до збереження.
2. **Що показує git diff?**
   Показує різницю (додані `+` та видалені `-` рядки) між файлами у робочій папці та останнім збереженим станом.
3. **Чим відрізняється git switch main від git merge?**
   `git switch` перемикає робочу гілку, а `git merge` бере зміни з іншої гілки і вливає їх у поточну.
4. **Чому виник конфлікт і як ти його розв'язав?**
   Конфлікт виник, бо один рядок змінили по-різному у двох гілках. Розв'язав вручну: видалив службові символи Git і залишив потрібний текст.
5. **Скільки commit-ів у твоїй історії?**
